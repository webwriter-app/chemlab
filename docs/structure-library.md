# ChemLab structure library

The library supplies offline structures for the existing chemical catalog. It is separate from ChemLab's dosing and equilibrium models. Molecule Builder shows the archived structure with its source. ChemLab checks a returned structure against the catalog and the worksheet's reagent permissions before selecting a dose.

## Data and coverage

- `data/structures/catalog.generated.json` includes PubChem molecular graphs and matching PubChem3D computed conformers, measured NIST bond lengths for six diatomic species, and experimental CIF unit cells from the Crystallography Open Database. When a PubChem record has no matching conformer, the generator attempts RDKit ETKDG followed by MMFF or UFF where parameterized. The widget identifies calculated coordinates as estimates or PubChem conformers. [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest) · [NIST experimental diatomic geometries](https://cccbdb.nist.gov/diatomicexpbondx.asp) · [COD](https://doi.org/10.1093/nar/gkr900) · [ETKDG](https://doi.org/10.1021/acs.jcim.5b00654)
- The 156 entries include solids, analytical solutes, explicitly modeled aqueous ions, mixtures, and polymers. The editor shows structures or representative constituents for 151 entries. Liquid paraffin, Schiff reagent, litmus, red cabbage extract, and olive oil are identified as mixtures with no unique structure. Polymeric materials with a regular repeat display a short, capped example. Mixed binders, indications of polymer chain length, and crystal phases in the real material depend on the specimen. [IUPAC definition of a constitutional repeating unit](https://goldbook.iupac.org/terms/view/C01286)
- Metal lookup covers the periodic table's metal categories and elements 109–116, whose group classification does not establish a bulk phase. The 74 sourced entries use documented reference phases from ASE, experimental CIFs for phases with more complex bases, or published metallic cells for Pm, Cm, Bk, Cf, and Es. The 18 unavailable entries represent Fr and Fm through the synthetic metals and candidate metals beyond Fm. Hg is explicitly the solid phase below 234.3 K. Lattice parameters in the periodic table refer to the stored phase. They are independent of the temperature mode. [ASE reference data](https://ase.gitlab.io/ase/ase/data.html) · [Promethium metal diffraction](https://www.sciencedirect.com/science/article/pii/0022508871901019) · [Actinide metal reference table](https://escholarship.org/content/qt98q8p9cg/qt98q8p9cg.pdf)
- The CIF converter applies the reported symmetry and retains measured coordinates, including partial site occupancies. When a measurement provided no hydrogen positions, the crystal view says so. Partially occupied sites are translucent and their occupancies are listed in the inspector. Examples of reference polymorphs include graphite, calcite, and α-quartz. The catalog's potassium sodium tartrate preview explicitly names the tetrahydrate.
- Crystal colours group sites by their curated ion formula. The rules in `crystalIons` use element membership and, for hydrates, short periodic neighbour distances to distinguish polyatomic ions from neutral water. These labels are display metadata and leave imported formal charges and the simulation recipes intact. [Neutron diffraction dataset for copper sulfate pentahydrate](https://www.crystallography.net/cod/9008253.html)
- **Lattice positions** marks the translation points of the displayed cell, including the corners and any centring positions. The points use the stored cell setting. Imported or edited cells without symmetry metadata are shown as primitive. [IUCr centring vectors](https://www.iucr.org/__data/iucr/cifdic_html/3_orig/CORE_DIC/Ispace_group.centring_type.html)
- For editor graphs, **Fit geometry** uses the local VSEPR layout for supported acyclic structures. A deterministic distance-constraint fallback uses approximate bond lengths, angles, and nonbonded separation for rings and unsupported coordination. A calculated ring uses one plausible geometry. Energies, conformational populations, and stereochemical preferences are outside this estimator.
- **Valence electrons** in 3D draws dots for the bonding electrons in the graph and the nonbonding electrons assigned by a main-group Lewis count. Translucent ellipsoids show the approximate regions they occupy. Transition-metal nonbonding shells, delocalized electron density, and quantum orbitals are outside this model.

## Regenerating the checked-in data

Use Python with ASE 3.26.0, Gemmi 0.7.3, and RDKit 2025.3.5. `data/structures/sources.json` identifies the records, molecular connectivity, hand-curated representations, and the coverage set. The generated snapshots are shipped with the widgets and require no runtime network access.

1. Put PubChem's computed conformer SDFs in `CACHE/pubchem/<CID>.sdf`. The endpoint is `/rest/pug/compound/cid/<CID>/SDF?record_type=3d`. Save a record only if the request succeeds. Missing records fall back to a local estimate.
2. Query COD with the comma-separated archive IDs from `crystals` and `metalCifs`, using `format=zip`. Save the CIF archive in `CACHE/cod-selected.zip`. [COD REST query formats](https://wiki.crystallography.net/RESTful_API/)
3. Run `python scripts/generate-structure-library.py CACHE`. Inspect the generated changes and run `tests/molecule-builder.test.ts` using the repository test command. The suite validates coverage, site coordinates and occupancies, example geometries, and dose matching.
